        Память персонажа

        Порядок таблицы — причинный (seq). Порядок контекста Beta v1 остаётся legacy (created_at, event_id) и намеренно отличается. «Загружено» не равно «доставлено».

        Сцена

        Условие сцены — ситуационный ввод оператора. Это не данные пакета персонажа и не постоянная память. Без сцены контекст Beta v1 не меняется. 

        
        
        
      
        

      
        
        
        
          
        Состояние (Runtime State)
        
          
        
            Runtime State — это значения, которые оператор явно подтвердил как
            текущее состояние выполнения. Это не Принятый пакет персонажа, не
            память разговора, не вывод модели и не сцена. Здесь нет
            автоматической эволюции: ни память, ни ответ модели, ни сцена, ни
            канон сами по себе не меняют состояние. Только явные действия
            оператора ниже. Числовые домены используют шкалу −100..+100;
            отсутствие ключа означает «не инициализировано».
